# Nexus Trading

Evolutionary trading strategy discovery using genetic algorithms.

## Features

- **Genetic Algorithm** — Tournament selection, crossover, mutation, elitism, speciation
- **Walk-Forward Validation** — Out-of-sample testing on real market data
- **Continual Learning** — Real-time market data adaptation every 5 minutes
- **Multi-Exchange** — Binance, Bybit, Kraken, Hyperliquid
- **Regime Detection** — Adapts to changing market conditions
